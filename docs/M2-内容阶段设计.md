# M2 内容阶段设计

日期：2026-09-04 ｜ 对应里程碑：M2 ｜ 前置：M0/M1（已完成，9 项自动化测试全绿）
验收标准：朋友从打开页面到打完一局全程不需要问"然后呢"——选人、选图、对战、结算、再来一局，一路顺畅。

## 1. 两个初始角色（数据驱动，加角色=填数据不写代码）

| | **疾风**（角色0） | **磐石**（角色1） |
|---|---|---|
| 定位 | 快速连击型 | 重锤一击型 |
| 移动速度 | ×1.12 | ×0.88 |
| 跳跃力 | ×1.06 | ×0.95 |
| 体重（抗击飞） | 0.92（更容易飞） | 1.18（更扛飞） |
| 空手招式 | 伤害8 / 快速出拳（前摇4帧） | 伤害11 / 慢重拳（前摇6帧，击飞×1.25） |
| **专属武器** | **双刃**：伤害7、更长更快（判定76宽/前摇3/后摇6） | **巨锤**：伤害13、又大又重（判定88宽/击飞×1.5/前摇8） |

- M1 的防御/闪避/蓄力为全角色通用机制，蓄力倍率沿用（×1.6/×2.4）
- 角色0 的空手数据 = M0 白盒基线数据，保证回归测试语义不变

## 2. 武器系统（借鉴 Brawlhalla，按用户需求裁剪）

- 武器每隔 15 秒在地图的固定刷新点轮换掉落（确定性循环，不引入随机）
- 走到武器上**自动拾取**，拾取有 12 帧起手硬直（不能白捡还白打）
- **专属加成**：用自己角色的专属武器 = 100% 威力；捡到对方的武器 = 70% 威力（"专属武器发挥最大成果"——用户原话）
- **死亡掉落**：角色出界死亡时武器随之消失，等下一轮刷新——规则简单清晰
- 空手/武器只是两套不同的招式数据，通用机制（防御闪避蓄力）完全一致

## 3. 第二张地图「双峰」

- 主岛裂成左右两根石柱（中间是深渊裂缝），中央+两侧共三块软平台
- 考验跨裂缝追击与回场，和「孤岛」（地图0）节奏完全不同
- 地图 = 纯数据（平台列表 + 武器刷新点），选图在菜单完成

## 4. 对局流程

```
标题菜单（1双人 / 2人机 / 3改键）
  → P1 选角色（A/D 切换，F 确认）
  → P2 选角色（人机模式下由 P1 代电脑选；←/→ 切换，小键盘0 确认）
  → 选地图（1/2 键）
  → 对战
  → 结算（R 同配置再来 / C 重选角色 / Esc 回标题）
```

## 5. 界面化改键（标题菜单按 3）

- 列出 P1/P2 全部 14 个绑定项，W/S 上下选，回车进入"按新键"，Esc 保存返回
- 修改存入 localStorage，刷新页面不丢——机房场景（没小键盘的笔记本）直接受益
- 改键属于输入层，不进模拟核心，不影响确定性

## 6. AI 适配

- 无武器时若场上有武器 → 顺路去捡（行为表新增 pickup 意图）
- 拾取/使用武器对 AI 透明：招式数据变了，输入接口没变
- 回场逻辑适配多地图：向最近的实体平台中心移动

## 7. 已知简化（诚实记录）

1. 武器招式暂时是"强化版横扫"，还没有真正的连段链（3连击是 M3 后的内容）
2. 没有投技、没有武器投掷
3. 选人界面是白盒文字菜单（角色头像/立绘等 M4）
4. 角色1 的数据平衡只做了纸面计算，实战平衡靠用户试玩反馈调

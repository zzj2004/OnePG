# M0 白盒原型设计

日期：2026-09-04 ｜ 对应里程碑：M0 ｜ 验收人：用户（试玩，认可"手感好玩"即通过）

## 1. M0 是什么、不是什么

**是**：两个色块小人在孤岛地图上跑、跳、二段跳、下穿平台、用一记基础攻击把对方打飞、出界扣命、三命定胜负。本地双人同键盘。

**不是**：没有正式美术、没有多角色、没有武器系统、没有AI、没有联机。这些分别在 M1~M3。M0 检验的只有一件事：**移动和击飞的手感**。

## 2. 默认键位（M0 阶段改键 = 编辑 `src/input/keys.ts`，M2 后做界面改键）

| 动作 | P1（红） | P2（蓝） | 说明 |
|---|---|---|---|
| 左右移动 | A / D | ← / → | 转向即时生效，跟手 |
| 跳跃 | W | ↑ 或 空格 | 空中可再跳一次（二段跳） |
| 下/快速下落 | S | ↓ | 空中按住=加速下落 |
| **下穿平台** | 站软平台上按 S+W | 站软平台上按 ↓+跳 | 用户习惯方案：下+跳 |
| 攻击 | F | 小键盘0 或 / | 一记基础攻击（M0 唯一招式） |
| 重新开始 | R | R | 对局结束后 |

## 3. 场地（孤岛）

```
 出界线（上方 -560）~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~
        ┌─────────┐            ← 高台软平台（可下穿、可从下方跳上穿）
     ┌──────┐  ┌──────┐        ← 两块软平台
───────────────────────────────  ← 主岛（实体地面，不可下穿）
   深渊  深渊    深渊    深渊
 出界线（下方 +940，左右 ±360/1640）=死亡
```

- 逻辑分辨率 1280×720，固定 60 帧/秒
- 所有平台都是"单向"的：从下往上跳能穿过，下落时才站上去
- 出界（越出四条边界线）= 死，扣一条命，中央上空重生（短暂无敌）

## 4. 核心机制清单

| 机制 | 说明 |
|---|---|
| 无血条 | 伤害累积百分比，伤害越高被击飞越远 |
| 二段跳 | 地面跳 1 次 + 空中跳 1 次 |
| 土狼时间 | 走出平台边缘后 6 帧内仍可起跳（防"我明明按了"） |
| 跳跃预输入 | 落地前 6 帧内按跳，落地瞬间自动起跳（同理） |
| 快速下落 | 空中按住下，下落提速 |
| 击飞 | 被击飞力度 = 基础值 + 当前伤害 × 系数 |
| 受击僵直 | 被打后短暂无法操作，僵直时长随击飞力度增长 |
| **顿帧** | 命中瞬间全场冻结 6 帧——打击感的种子，M0 就要有 |
| 命中即锁 | 一次攻击挥出只命中一次 |
| 重生无敌 | 重生后 90 帧无敌（闪烁提示），伤害清零 |

## 5. 手感参数面板（全部集中在 `src/core/constants.ts`，带中文注释，改完保存即热更新）

| 参数 | 默认值 | 拧大/拧小的效果 |
|---|---|---|
| GROUND_MAX_SPEED | 7 px/帧 | 跑得快/慢 |
| GROUND_ACCEL | 1.4 | 起步肉/贼 |
| GROUND_FRICTION | 1.0 | 刹车滑/脆 |
| AIR_ACCEL | 0.9 | 空中飘/灵 |
| JUMP_VEL / DOUBLE_JUMP_VEL | 16 / 15 | 跳得高/矮 |
| GRAVITY | 0.85 | 下落沉/浮 |
| FALL_CAP / FAST_FALL_CAP | 14 / 20 | 下落极限 |
| COYOTE_FRAMES / JUMP_BUFFER_FRAMES | 6 / 6 | 容错窗口 |
| DROP_THROUGH_FRAMES | 12 | 下穿后多快"恢复碰撞" |
| ATTACK_STARTUP/ACTIVE/RECOVERY | 4/3/8 帧 | 出招前摇/判定/后摇 |
| ATTACK_DAMAGE | 8 | 每击伤害 |
| KNOCKBACK_BASE / _SCALE / _CAP | 9 / 0.22 / 30 | 击飞曲线三旋钮 |
| HITSTUN_BASE / _SCALE | 12 / 0.5 | 受击僵直曲线 |
| HITSTOP_FRAMES | 6 | 顿帧长度（打击感总开关） |
| START_STOCKS | 3 | 每人命数 |

**单位说明**：模拟核心不使用真实时间，全部以"帧"（1/60 秒）为节拍、以"像素/帧"为速度单位——这是确定性的前提，也是所有参数可互相换算的原因。

## 6. 架构（兑现技术选型承诺的最小版本）

```
src/
  core/        确定性模拟：纯计算，禁止碰 DOM/时间/随机数 → 可自动化测试
    constants.ts   手感参数面板
    stage.ts       场地数据（数据驱动第一块试验田）
    types.ts       状态与输入类型
    simulation.ts  step(状态, 输入) 纯函数式推进
  input/keys.ts    键位映射（配置即数据）
  render/renderer.ts  表现层（PixiJS 画色块），可整体替换
  main.ts          固定步长主循环（累积器模式）+ 键盘监听
  tests/determinism.ts  确定性测试 + 命中冒烟测试
```

- 主循环：真实时间累积 → 每 1/60 秒推进一步模拟 → 每帧渲染最新状态。模拟与渲染解耦，将来联机时把"键盘输入"换成"网络输入"，核心零改动。
- `npm run test`：① 同一输入序列跑两遍，逐帧快照必须完全一致（确定性）；② 脚本化输入必须能命中并造成伤害（战斗逻辑冒烟）。

## 7. 已知简化（诚实记录，不属于 M0 验收范围）

1. 主岛侧面不做人墙碰撞（从侧面被击飞会直接落深渊）——孤岛规则下可接受，先不造
2. 攻击是"一记横扫"，无上下方向、无蓄力（蓄力+可转身在 M1）
3. 被击飞出屏上方时无屏外指示箭头（M4 打磨）
4. 防御/闪避是 M1 内容，M0 只能跑跳躲

## 8. 运行与验收步骤

1. `npm run dev` → 浏览器打开提示的地址（默认 http://localhost:5173）
2. 双人各占键盘一侧试玩 10 分钟，重点感受：起跳/二段跳的利落度、转向跟手度、被击飞的"爽"度、顿帧的"打击感"
3. 觉得不对劲的，直接说感受（"跳起来发飘""打人没分量"），我来换算成参数调整
4. `npm run build:usb` 产出 `dist-usb/OnePG.html`——单文件，拷 U 盘双击即玩

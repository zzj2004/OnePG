# M4c 移动端触屏支持设计

日期：2026-09-05 ｜ 对应里程碑：M4（打磨阶段第二包） ｜ 前置：M0~M3、M4a
目标：让拿手机的朋友也能联机——画面自动缩放适配小屏，屏幕上出现虚拟按键。

## 1. 内容

1. **画面自适应缩放**：1280×720 的画面按窗口等比缩放居中（手机竖屏会上下留黑边，横屏体验最佳）
2. **触屏按钮层**：左下方向簇（←/→/↑/↓），右下三个动作键（攻击/防御/闪避）
   - 按下即按住、松手即松开，和键盘完全等价
   - 触屏设备（pointer: coarse）自动显示；电脑上默认隐藏
   - 联机时按钮映射到"自己的槽位"（房主=红方，对手=蓝方）
3. 按钮用 DOM 实现（不用 canvas 命中检测），样式半透明不挡视线

## 2. 架构

- `src/input/touch.ts`：TouchControls 类，维护触屏按住的动作集合
- 主循环合成输入：本方输入 = 键盘按键 **或** 触屏按住（逐动作合并）
- 单机模式触屏控制 P1；联机模式触屏控制自己的槽位——与键盘同规则
- 模拟核心零改动

## 3. 已知简化（诚实记录）

- 不做虚拟摇杆（十字键对格斗游戏够用且更准）
- 不做按键位置自定义
- 手机竖屏体验一般，建议横屏

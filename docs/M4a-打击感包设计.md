# M4a 打击感包设计

日期：2026-09-05 ｜ 对应里程碑：M4（打磨阶段第一包） ｜ 前置：M0~M3
目标：让"打中"这件事在耳朵和眼睛上都有回报。用户定调：打击感是全游戏最高优先级。

## 1. 内容

1. **程序生成音效**（Web Audio，零音频素材）：
   挥拳呼啸 / 命中闷响（重击更低更沉）/ 盾牌格挡金属声 / 闪避呼啸 / KO 爆响 /
   拾取双音上扬 / 倒计时哔哔 + 开战高音 / 胜利琶音
2. **屏幕震动**：命中按伤害强度震，KO 大震，随时间衰减
3. **粒子**：命中火花（颜色随蓄力档位）、KO 爆裂环、拾取闪光、防御格挡火星

## 2. 架构原则：核心零改动

- 音效与粒子都是**表现层**，不需要确定性（不影响联机一致性）
- 事件不来自模拟核心，而是**渲染层对前后两帧状态做差分**推导：
  伤害上涨=命中、命数下降=KO、武器计数变化=拾取、护盾值掉但伤害没涨=格挡、
  attackActive 从 false 变 true=出招
- 好处：模拟核心一行不动 → 30 项自动化测试应当原样全绿；联机两端各自 local 表现，互不影响

## 3. 已知简化

- 音量/混音未做设置界面（M4 后续）；粒子数量上限 300 防止低端机掉帧
- KO 慢动作需要核心支持"时间缩放"，本包不做

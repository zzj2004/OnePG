# M1 战斗系统设计

日期：2026-09-04 ｜ 对应里程碑：M1 ｜ 前置：M0 白盒原型（已完成并自动化验证）
验收标准：用户能和电脑完整打完一局（能赢也能输），新机制在试玩中可感知、可反制。

## 1. 本阶段新增什么

在 M0（跑/跳/击飞/出界）之上，补齐格斗博弈的三个支点 + 第一个陪练：

1. **防御（护盾）**——挡住攻击，但会被打碎
2. **闪避（无敌帧）**——躲过攻击，但不能乱按
3. **蓄力攻击**——按住不放蓄力，松手放出重击；**蓄力中可以转身**（立项文档第10节用户拍板的差异点）
4. **陪练 AI**——会追人、会出手、会挡、会回场；不聪明，但能陪你打完整局
5. **开局菜单**——按 1 本地双人 / 按 2 挑战电脑

## 2. 新增键位（M1）

| 动作 | P1 | P2 | 说明 |
|---|---|---|---|
| 防御 | G | 小键盘1 或 句号键 | 地面按住生效；移动/跳跃全部锁定 |
| 闪避 | H | 小键盘2 或 右Shift | 点按；地面=翻滚，空中=空中闪避 |
| 蓄力攻击 | 按住F不放 | 按住攻击键不放 | 松手放出；空中攻击不蓄力 |

## 3. 机制细节

### 3.1 防御（护盾）

- 地面按住防御键进入护盾状态：移动、跳跃、攻击、闪避全部锁定
- 被攻击命中护盾：**不掉血、不被击飞**，护盾值扣 `16 + 12×蓄力档位`，双方受推力（防御方后退大、攻方后退小）
- 护盾值 100 上限；非防御状态每帧回复 0.15（约 9/秒）
- 护盾值 ≤0 → **破防**：90 帧大硬直（等于白吃一套连招），且回复到 15 以上才能再开盾——防止无脑龟壳
- 松盾后有 6 帧收盾硬直才能行动（防"盾闪光棍"）

### 3.2 闪避（无敌帧）

- 点按闪避：地面=向输入方向翻滚（无输入=原地闪），空中=空中闪避（水平漂移+竖直速度衰减）
- **无敌区间**：地面第 4~16 帧，空中第 4~18 帧——必须预判对方出招时机，不是万能钥匙
- 动作结束 6 帧收招硬直；冷却 60 帧（从起手算）
- 闪避中不能做任何其他动作；被击飞（受击僵直）中不能闪避

### 3.3 蓄力攻击

- 地面按住攻击键：进入蓄力。**蓄力中不能移动，但可以转身**（←/→ 只改朝向不改位置）——这是和 Brawlhalla 的刻意差异
- 松手放出攻击，伤害/击飞按档位放大：

| 档位 | 需要按住 | 伤害倍率 | 击飞倍率 |
|---|---|---|---|
| 0（点击） | — | ×1.0 | ×1.0 |
| 1 | ≥20 帧 | ×1.6 | ×1.5 |
| 2（满蓄） | ≥45 帧 | ×2.4 | ×2.2（击飞上限同步放大） |

- 按住满 75 帧自动放出；蓄力中被命中 → 蓄力取消（风险自负）
- 空中按攻击 = 立即出招（不蓄力）

### 3.4 陪练 AI（确定性）

- AI 在模拟核心内部运行，产出和键盘一模一样的 `PlayerInput`——不破坏确定性，将来联机架构不用改
- **禁止 Math.random**：用固定种子的整数 LCG 伪随机（同种子同行为，可测试可回放）
- 决策循环：每 9 帧重新评估一次局势，行为表：

| 局势 | 行为 |
|---|---|
| 自己在场外/坠落中 | **回场**：向岛心移动+看准时机二段跳 |
| 对手在攻击判定中 | 概率防御 / 概率闪避 |
| 对手近身 | 概率出拳 / 对手高伤时概率蓄力重击 |
| 对手远 | 追击（偶尔停顿、偶尔后撤，避免机械感） |

- 难度定位："笨但完整"——它会犯错，但会回场，能陪你打完整局

## 4. 手感参数面板新增（`src/core/constants.ts`）

| 参数 | 默认值 | 效果 |
|---|---|---|
| SHIELD_MAX / REGEN | 100 / 0.15每帧 | 盾的厚度/回复速度 |
| SHIELD_COST_BASE / PER_TIER | 16 / 12 | 挡刀代价（随蓄力档位涨） |
| SHIELD_BREAK_STUN | 90帧 | 破防惩罚 |
| SHIELD_DROP_LAG | 6帧 | 收盾硬直 |
| DODGE_FRAMES / IFRAMES | 22 / [4,16) | 翻滚时长/无敌窗 |
| AIR_DODGE_FRAMES / IFRAMES | 26 / [4,18) | 空中闪避 |
| DODGE_COOLDOWN | 60帧 | 防止无限翻滚 |
| CHARGE_T1 / T2 / AUTO_RELEASE | 20 / 45 / 75帧 | 蓄力档位线 |
| CHARGE_DMG_MULT | ×1 / ×1.6 / ×2.4 | 蓄力伤害曲线 |
| CHARGE_KB_MULT | ×1 / ×1.5 / ×2.2 | 蓄力击飞曲线 |
| AI_THINK_INTERVAL | 9帧 | AI 反应速度（越小越强） |

## 5. 白盒可视化（找手感用）

- 护盾：角色脚下的圆环，颜色随护盾值从青→红，碎盾瞬间消失
- 蓄力：角色外框发光，颜色随档位 黄→橙→红，带脉冲
- 闪避：无敌帧期间角色半透明
- AI 接管 P2 时，HUD 显示"电脑"

## 6. 已知简化（诚实记录）

1. 没有投技——理论上护盾接近无解，只能靠破防惩罚和绕后克制；投技是 M2 内容
2. AI 不做追击连段、不做淤批（edge guard），只会一换一
3. 闪避无敌不区分上中下段（本来也没有上下段判定）
4. 菜单是白盒按钮（按数字键），正式 UI 在 M2

## 7. 自动化测试计划（`npm run test`）

1. M0 全部旧测试必须原样通过（防回归）
2. 蓄力：按住 70 帧松开命中 → 伤害 ≈ 8×2.4 = 19.2
3. 防御：开盾挨打 → 掉盾不掉血
4. 闪避：无敌窗内挨打 → 既不掉盾也不掉血
5. AI 完整对局：人机模式跑 90 秒，AI 必须能击败站桩 P1（证明"能完整打赢一局人机"）
6. 确定性扩展：人机模式整局跑两遍，快照完全一致

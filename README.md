# OnePG — 网页平台格斗游戏

> 把对手打出场外就赢。点开链接就能玩，不用安装任何东西。

**🎮 立即试玩：<https://zzj2004.github.io/OnePG/>**（推荐电脑 + Chrome/Edge，和朋友同一 WiFi 可联机）

OnePG（One People Game）是一款 2D 平台格斗游戏，玩法对标《任天堂明星大乱斗》《Brawlhalla》：
没有血条——伤害越高被打得越远，把对手打出场地边界（或打进深渊）就扣命，三命定胜负。

由两个人利用业余时间开发：一个人出想法和手感反馈，一个人写全部代码。
开发流程：想法收敛 → 前期立项 → 原型设计 → 开发落地 → 测试上线，每个里程碑都有可玩版本。

## 玩法特性

- **4 名角色**，各有空手 + 专属武器两套三段连招：
  - **疾风**（双刃）：快速连击型，移动最快但更容易被击飞
  - **磐石**（巨锤）：重锤一击型，又肉又痛但笨重
  - **惊雷**（长枪）：均衡长青型，枪判定全场最长
  - **青鸾**（战扇）：空中特化型，跳得最高、全场最轻
- **三段连招**：攻击命中后连按攻击接段，第三段把对手挑上天
- **训练场**：无限假人 + 连击统计（当前/上次/最高，段数与伤害），R 一键重置——连招在这里练成
- **蓄力重击**：按住攻击蓄力，松手放出 2.4 倍伤害——**蓄力中可以转身**
- **防御 / 闪避**：护盾会被打碎（碎盾大硬直），闪避有无敌帧
- **武器拾取**：四种武器周期刷新，捡到本命武器威力 100%，捡对手的只有 70%
- **3 张地图**：孤岛（经典对称）、双峰（裂缝博弈）、窄桥（侧边出界更近的击飞对决）
- **本地双人 / 人机 / 局域网联机**：锁帧同步 + 状态校验和，断线 10 秒内可重连
- **程序生成音频**：全部音效与战斗 BGM 由代码合成，零音频素材

## 怎么玩

### 打开游戏

- **开发模式**：安装 [Node.js](https://nodejs.org) 后，在本目录执行 `npm install && npm run dev`，浏览器打开 http://localhost:5173
- **单文件版**：`dist-usb/OnePG.html`，拷进 U 盘，双击用浏览器打开即玩（免安装、单机功能免联网）

### 操作（默认键位，标题按 3 可改）

| 动作 | P1（红） | P2（蓝） | 手柄（Xbox 布局） |
|---|---|---|---|
| 移动 | A / D | ← / → | 左摇杆 / 十字键 |
| 冲刺 | 双击 A/A 或 D/D | 双击 ←/← 或 →/→ | 快速双推摇杆 |
| 跳跃（可二段） | W 或 K | ↑ 或 空格 | A |
| 下 / 快速下落 | S | ↓ | 摇杆下 |
| 下穿薄平台 | S+W | ↓+跳 | 摇杆下+A |
| 攻击 / 蓄力 | J（按住蓄力） | 小键盘0 | X |
| 防御 | G | 小键盘1 | B |
| 闪避（朝移动方向翻滚） | L | 小键盘2 | Y |

标题界面：`5` 新手教学（12 步，含连招与武器） · `6` 训练场（连击统计） · `1` 本地双人 · `2` 挑战电脑（三档难度） · `3` 设置 · `4` 联机

### 局域网联机

1. 一台电脑：标题按 `4` → `1` 创建房间，记下 4 位房间码
2. 同一 WiFi 下的伙伴：浏览器打开你的地址（如 `http://192.168.x.x:5173`）→ `4` → `2` → 输入房间码
3. 各自选角色 → 房主选地图 → 开战
4. 中途断线？10 秒内回到房间自动重开此局

> 联机撮合走 PeerJS 公共服务，对战数据在同一局域网内直连。
> 两台设备都需要能上网（浏览器安全限制）；手机等触屏设备会自动显示虚拟按键。

## 技术架构（写给想抄作业的人）

- **TypeScript + PixiJS + Vite**，无重量级游戏引擎
- **确定性模拟核心**（`src/core/`）：固定 60 帧/秒步长，纯函数式推进，禁用随机数与真实时间——
  同样的输入序列在任何电脑上算出完全一致的对局过程
- **联机 = 锁帧同步**（`src/net/`）：每帧只传 1 字节按键位，不传画面；每 60 帧交换状态校验和防"两端算岔"
- **角色/招式/地图全部数据驱动**（`src/core/characters.ts`、`stage.ts`）：加角色 = 填一张数据表
- **表现层完全隔离**（`src/render/`、`src/audio/`）：音效、粒子、震屏由状态差分驱动，核心零感知
- **48 项自动化测试**（`npm run test`）：确定性回放、机制专项、联机协议、手柄映射；推送即跑 CI

```
npm run dev        # 开发服务器（热更新）
npm run test       # 全部自动化测试
npm run typecheck  # TypeScript 检查
npm run build      # 网页版构建 → dist-web/
npm run build:usb  # 单文件版构建 → dist-usb/OnePG.html
```

已知取舍（不是 bug）：

- 联机撮合依赖 PeerJS 公共服务，若服务关停需自建撮合
- 断线重连采用"重开此局"方案（不做帧级续战）
- 移动端可玩（触屏虚拟按键）但按 PC 优先打磨
